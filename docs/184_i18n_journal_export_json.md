# Patch 184 — Internationalisation Journal & export JSON

Ce patch poursuit la transition bilingue français / anglais.

## Périmètre migré

- écran **Journal d’activité** ;
- dialogue de suppression du journal local ;
- messages d’état du journal ;
- écran **Export JSON** ;
- cartouche d’introduction de l’export ;
- messages de copie / sauvegarde ;
- avertissements de chargement du journal ;
- aperçu JSON.

## Points volontairement conservés

Les données produites par l’utilisateur ne sont pas traduites : noms de campagnes, descriptions, SI, directeurs, évènements déjà enregistrés et chemins de fichiers restent inchangés.

Les titres historiques déjà stockés dans le journal local peuvent rester dans la langue dans laquelle ils ont été créés. Les nouveaux libellés d’interface autour du journal sont, eux, traduits via les fichiers JSON.
