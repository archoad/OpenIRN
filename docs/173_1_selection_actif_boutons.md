# Patch 173.1 — Sélection d’actif par boutons

Ce correctif remplace la liste verticale des actifs dans le cartouche **Notation par actif** par une suite compacte de boutons.

## Changements

- suppression de la liste verticale trop haute ;
- affichage des actifs sous forme de boutons compacts ;
- conservation du compteur de progression par actif ;
- l’actif sélectionné reste mis en évidence ;
- le clic sur un bouton sélectionne la grille IRN de l’actif concerné ;
- les descriptions longues sont accessibles en infobulle.

Aucun changement serveur ni base de données.
