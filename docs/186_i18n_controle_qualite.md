# Patch 186 — Internationalisation du contrôle qualité

Ce patch poursuit la transition bilingue français / anglais d’OpenIRN.

## Périmètre

- écran **Contrôle qualité** ;
- cartouche de statut de la campagne ;
- synthèse des informations manquantes ;
- progression qualité ;
- critères non renseignés ;
- justifications manquantes ;
- libellés transverses utilisés par cet écran.

## Hors périmètre

Les données saisies par les utilisateurs ne sont pas traduites automatiquement : noms de campagnes, SI, référentiel, critères et libellés métier restent ceux de la donnée source.
